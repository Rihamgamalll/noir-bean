NØIR BEAN — نسخة الواجهة الجاهزة للربط بالباك إند

تم تنفيذ:
1) استخدام public/bean-cafe.png كخلفية لقسم Liquid Alchemy مع overlays تحفظ وضوح اللبن والقهوة والتلج.
2) استخدام نفس الخلفية في Closing Scene مع معالجة داكنة لقراءة النص.
3) قائمة حساب في الـNavbar تشمل My Account / My Orders / Favorites / Admin Dashboard.
4) صفحة Favorites وحفظ المفضلات حاليًا في localStorage لحين ربط المستخدم وقاعدة البيانات.
5) صفحة My Account جاهزة للربط.
6) صفحة My Orders جاهزة للربط.
7) Admin Dashboard الموجود بالمشروع ما زال متصلًا بـ API الطلبات المحلية.
8) إضافة اختيار Coffee Beans عند تخصيص المشروب: House Blend / Brazilian / Colombian / Ethiopian / Decaf.
9) حفظ نوع البن داخل السلة وPayload الطلب ورسالة WhatsApp.
10) Chatbot عربي/إنجليزي يعمل حاليًا بمنطق متجر آمن وقاعدة المنيو الفعلية، مع رد طبي حذر وعدم ادعاء التشخيص.
11) إصلاح TypeScript في scroll-experience.tsx.

مهم قبل الإنتاج:
- الشات بوت الحالي Frontend rule-based وليس نموذج AI مفتوحًا. للذكاء الاصطناعي الكامل اربطه لاحقًا بـ API آمن على السيرفر وقاعدة معرفة المتجر.
- Favorites / Account / My Orders تحتاج Auth + Database حتى تثبت عبر الأجهزة والحسابات.
- لا تضع مفاتيح API داخل ملفات Frontend.

التشغيل:
npm install
npm run dev

تم تشغيل tsc --noEmit بنجاح قبل إزالة node_modules من النسخة المضغوطة.

تحديث الشات بوت:
