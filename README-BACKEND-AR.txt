NØIR BEAN — التشغيل والطلبات

1) شغلي المشروع:
   npm install
   npm run dev

2) صفحة المنيو:
   http://localhost:3000/menu

3) صفحة الأدمن:
   http://localhost:3000/admin
   كلمة المرور الافتراضية للتجربة: noir2026

4) الطلب عند تأكيده:
   - يتحفظ محليًا داخل data/orders.json
   - يفتح واتساب على الرقم 201013290912 برسالة جاهزة
   - يظهر فورًا في لوحة الأدمن

5) قبل الرفع أونلاين:
   - انسخي .env.example إلى .env.local
   - غيري ADMIN_PASSWORD
   - التخزين الحالي مناسب للتجربة المحلية. على Vercel استخدمي Supabase لأن نظام ملفات Vercel غير دائم.
